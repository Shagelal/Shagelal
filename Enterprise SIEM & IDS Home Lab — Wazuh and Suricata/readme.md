# 🛡️ Home SOC Lab

> Building an enterprise-style Security Operations Center (SOC) using open-source security tools.

## 📖 Overview

This project documents my journey of building a complete Home SOC lab for learning Blue Team operations, Security Monitoring, Threat Detection, Digital Forensics, and Incident Response.

The goal is to simulate a real enterprise security environment using open-source technologies.

---

## 🛠️ Technologies

- Fedora Linux
- Wazuh SIEM
- Wazuh Dashboard
- Wazuh Indexer
- Filebeat
- Suricata IDS
- Kali Linux
- Tailscale
- Auditd
